# 懒猫文件选择器

`lzc-file-chooser-inject.js` 由懒猫官方文档提供，包含其文件选择器及依赖的许可证声明。此副本的 SHA-256 为 `4da22e7d0b3167de57a63cb5f31af13a2e98292a17c344ca71bce70331d453b5`。

雁字只启用头像文件输入拦截。懒猫网盘访问要求平台登录，只允许应用同源读取当前微服中的 PNG、JPEG 和 WebP 文件，文件权限由网盘服务校验。独立 Docker 或二进制使用浏览器的文件选择器。
